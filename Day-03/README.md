- Score: **9/10**

### Communication Practice
Practiced explaining the difference between `axis=0` and `axis=1`:

- `axis=0`: performs an operation down the rows, producing results for each column.
- `axis=1`: performs an operation across the columns, producing results for each row.

### Key Takeaway
NumPy provides efficient tools for numerical computing and is an important foundation for data analysis and Machine Learning.
